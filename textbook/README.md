# 個人用テキスト（印刷用 HTML）

介護福祉士国家試験講座「合格テキスト」の章ごとの印刷用ページです。B5（182×257mm）。

| ファイル | 内容 |
| --- | --- |
| `ch13-sougou-mondai.html` | 第13章 総合問題（全16ページ：表紙・目次・章扉・13-1〜13-3・演習・章末まとめ） |
| `textbook.css` | 全章で共通のスタイル（色・見出し・ポイント箱・表・ページ枠） |
| `assets/logo-mark.png` | ES ロゴ |

## 使い方

ブラウザで HTML を開き、上部の「印刷・PDFに保存」ボタン（または Ctrl/⌘+P）で印刷します。
用紙サイズは CSS（`@page`）で B5 に指定済み。「背景のグラフィック」をオンにしてください。

## ページの組み方

- 1ページ＝`<article class="sheet">`
- 本文エリア：奇数ページ `.area-odd`（右に章インデックス `.tab`）、偶数ページ `.area-even`、表紙は `.area-full`
- ページ番号：`.pn-odd`（右下）／`.pn-even`（左下）
- 本文の部品：`.sec`（節見出し）、`h3.t`、`.goal`、`.point`、`.scene`、`.trap`、`.quiz`、`.box`、表
