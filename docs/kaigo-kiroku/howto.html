使い方

1日5分の流れ

  • ホームの「今日の場面」を1つ書く（約5分）。
  • 「事実？解釈？」クイズを1回（10問・約2分）。
  • わからない言葉は「学ぶ」→「用語辞典」で調べる。

場面練習

  • 場面を読む → 記録項目（体温・食事量など）を入れる → 5W1Hで整理 → SOAPで書く → チェック、の順に進みます。
  • 80点以上でその場面は「できた」になります。80点に届かなかった場面は、ホームの「復習」に出てきます。

自動チェックで見ていること

  • O（客観的情報）に推測・感想・あいまいな言葉・ラベル（徘徊・不穏など）が入っていないか。
  • 時刻と数字があるか、本人の言葉が「」で書かれているか、A が判断・P が行動になっているか。
  • チェックは学習用の目安です。実際の職場の記録の書き方は、職場のルールに従ってください。

ふりがな・言語

右上の「設定」で、ふりがなのオン・オフと、日本語・ミャンマー語の切り替えができます。

注意

  • このアプリの場面と人物はすべて架空です。
  • 実在の利用者の名前や個人情報は入力しないでください。
