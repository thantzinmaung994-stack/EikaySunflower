# 講師が問題を追加する方法

このフォルダの3つのファイルに書くと、アプリに問題が増えます。Excel か Google スプレッドシートで開いて、1行に1問ずつ書きます。

| ファイル | 増えるもの | 無料／プレミアム |
| --- | --- | --- |
| `scenarios.csv` | 場面練習 | プレミアム（月額500円の会員だけ） |
| `quiz.csv` | 事実？解釈？クイズ | 無料 |
| `glossary.csv` | 用語辞典 | 無料 |

どのファイルにも **（記入例）** の行が1行入っています。「公開」の列が空なのでアプリには出ません。コピーして使ってください。

## 共通のルール
- **「公開」の列に「○」を入れた行だけ**がアプリに出ます。書きかけの行は空のままにしておけば大丈夫です。
- 1つのセルの中で改行してかまいません（Excel は Alt＋Enter、Google スプレッドシートは Ctrl＋Enter）。
- 人物はすべて架空にしてください。**実在の利用者の名前や、職場が分かる情報は書かないでください。**
- 保存は **CSV（UTF-8）** で。Google スプレッドシートなら「ファイル → ダウンロード → カンマ区切り形式（.csv）」。

## scenarios.csv（場面）

| 列 | 書き方 | 例 |
| --- | --- | --- |
| id | 半角の英小文字・数字・ハイフン。**最後を `-k01` `-k02` …** にする（`-01` は無料の場面用） | `meal-k01` |
| 種類 | バイタル／食事・水分／排泄／入浴／服薬／睡眠・夜間／口腔ケア／体位変換・移乗／活動・レク／様子・行動（認知症ケア）／ヒヤリハット・事故／申し送り | `食事・水分` |
| レベル | 1（やさしい）・2・3（むずかしい） | `2` |
| タイトル | 一覧に出る短い題 | `昼食でむせて、途中で食べるのをやめた` |
| 利用者 | 架空の人 | `ABさん（88歳・男性）` |
| 場面 | 受講生が読む文章。**わざと「〜と思う」「少し」「徘徊」などを混ぜる**と練習になります | |
| 正解の記録項目 | 「項目名=値」を1行に1つ。数字は幅も書ける（`所要時間=20±5`）。選ぶ項目はアプリの選択肢と同じ言葉で | `時刻=12:10`<br>`主食=3`<br>`むせ込み=2`<br>`食事形態=きざみ食` |
| 書くべき要点 | 「表示名｜文に入っているべき語（、で区切る）｜S・O・A・P」を1行に1つ。2つ以上 | `むせ込み2回｜2回｜O`<br>`本人の言葉｜苦しい｜S` |
| いつ〜どのように | 模範解答の 5W1H | |
| S・O・A・P | 模範解答 | |
| 解説 | 場面のどの言葉がなぜダメか、どう書けばよいか | |

**模範解答の決まり**（守らないとチェックで止まります）
- O に、時刻（`12:10` など）と数字を入れる。
- O に「〜と思う」「〜そう」「少し」「たくさん」「普通」「徘徊」「不穏」などを書かない（本人の言葉の「」の中はかまいません）。
- 「書くべき要点」の語が、模範解答の文の中に入っていること。

## quiz.csv（事実？解釈？クイズ）

| 列 | 書き方 |
| --- | --- |
| id | `k01` `k02` … |
| 記録の文 | 記録に書かれた1文 |
| 答え | `事実` か `解釈` |
| 解説 | なぜそうなのか（1〜2文） |
| 書き直し例 | 答えが「解釈」のときは必ず。事実だけで書き直した文 |

## glossary.csv（用語辞典）

| 列 | 書き方 |
| --- | --- |
| 用語 | 漢字の言葉 |
| 読み | ひらがな（略語はカタカナ） |
| グループ | 記録の基本／人間の尊厳と自立・介護の基本／介護過程・チームケア／社会の理解（制度・法律）／コミュニケーション／こころとからだのしくみ／バイタル・身体／発達と老化／認知症／障害の理解／医療的ケア・病気・薬／食事・水分／排泄／入浴・清潔／移動・体位／家事・住環境・福祉用具／安全・事故／感染対策／現場のことば／略語 |
| 意味 | やさしい日本語で1〜2文 |
| 記録での例 | 記録の書き方の例（あれば） |

## 書いたあと（開発担当・Claude に頼んでもよい）
1. ファイルを置き換える。
2. `npm run content:check` を実行する。おかしい行は「✕ content/quiz.csv 3行目：…」のように理由が出ます。場面は模範解答を自動で採点し、85点以上なら合格です。
3. `npm run my:sync` で、ミャンマー語訳の表（`translations/myanmar.csv`）に新しい行を足す。
4. `npm test` と `npm run build`。

まちがいのある行はアプリに出ないだけで、アプリが止まることはありません。
