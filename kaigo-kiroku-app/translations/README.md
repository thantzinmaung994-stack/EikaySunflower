# ミャンマー語訳の直し方 / မြန်မာဘာသာပြန် ပြင်နည်း

アプリのミャンマー語は、すべて **`myanmar.csv`** の1ファイルに入っています。

| 列 | 内容 |
| --- | --- |
| key | どこに表示される文か（**変えないでください**） |
| 種類 | 画面の文字・場面（あらすじ）・場面（解説）・クイズ（解説）・用語辞典 など |
| 日本語（原文・参考） | 元の日本語（参考用。ここを直してもアプリは変わりません） |
| **ミャンマー語** | **ここを直す・書き足す** |
| 確認済み | ネイティブが確認したら「○」などを入れる（アプリには影響しません） |

## 手順
1. `myanmar.csv` を Google スプレッドシート（ファイル → インポート）か Excel で開く。
2. 「ミャンマー語」の列だけを直す。空欄のところは、まだ訳がない文です（アプリでは日本語のまま表示されます）。
3. **CSV（UTF-8）** で保存して、このファイルを置き換える。
4. アプリを作り直す（`npm run build`）と反映されます。

## 開発者向け
- 場面・クイズ・用語を増やしたら `npm run my:sync` を実行すると、新しい行（ミャンマー語は空欄）が追加されます。入力済みの訳は消えません。
- `npm test` は、CSV の行とアプリの内容がずれていると失敗します。
