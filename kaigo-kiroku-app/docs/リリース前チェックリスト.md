- ☐ GitHub →「Settings」→「Pages」→「Custom domain」に `app.eikaysunflower.com` → Save →「Enforce HTTPS」
- ☐ 数分後、次の URL が開けることを確認する
  - https://app.eikaysunflower.com/kaigo-kiroku/privacy.html
  - https://app.eikaysunflower.com/kaigo-kiroku/support.html

## 3. App Store Connect（`docs/課金の設定手順.md` も参照）
- ☐ 有料 App 契約・銀行口座・税務情報

- ☐ サブスクリプショングループ「プレミアム」→ 製品ID `kaigo_premium_monthly`・1か月・500円・7日間無料お試し
- ☐ 受講生向けオファーコードを作る（必要なら）
- ☐ 掲載情報を入力（`docs/store/App Store掲載情報.md` をコピー）
- ☐ スクリーンショット6枚をアップロード（`docs/store/screenshots/`）
- ☐ App のプライバシー・年齢制限の質問に答える（掲載情報の表のとおり）

- ☐ Public API key（`appl_…`）をコピー

## 5. Mac での準備（`docs/iOS_TestFlight手順.md` も参照）
```bash
cd kaigo-kiroku-app
git pull
npm install
cp .env.example .env     # .env を開いて VITE_RC_IOS_KEY=appl_... に
npm run cap:ios          # Xcode が開く
```
- ☐ Xcode：Signing & Capabilities → Team を選ぶ → 「＋ Capability」→ **In-App Purchase**
- ☐ General → Version `1.0.0`、Build `1`

## 6. 実機テスト（Sandbox のテスト用 Apple ID で。お金はかかりません）
購入・課金
- ☐ 練習タブで 🔒 の場面を押す → プレミアム画面が開く
- ☐ 料金が「¥500/月」、お試しが「7日間」と出る
- ☐ 「無料で試してみる」→ Apple の確認画面 → 完了で 🔒 が外れる（場面・クイズ・用語・カード）
- ☐ アプリを消して入れ直す →「設定 → プレミアム → 購入を復元」で戻る
- ☐ 「受講生コードを使う」で Apple のコード入力画面が出る
- ☐ 「購入の管理・解約」で App Store の画面が開く

ほかの機能
- ☐ 毎日のお知らせ：設定で ON → 許可ダイアログ → 時刻を2分後にして、通知が届く
- ☐ 読み上げ：場面の 🔊、用語の 🔊 で日本語が聞こえる（マナーモードだと鳴らない端末がある）
- ☐ バックアップ：設定 →「書き出す」→「ファイルに保存」→ 別の端末（または消して入れ直し）で「読み込む」→ 記録が戻る
- ☐ ミャンマー語に切り替え、主な画面の文字が出る
- ☐ ふりがな ON/OFF
- ☐ 機内モードでも、練習・クイズ・用語が使える
- ☐ 画面の上下（ノッチ・ホームバー）に文字が隠れていない

## 7. 提出
- ☐ Product → Archive → Distribute App → App Store Connect → Upload
- ☐ TestFlight で講師・受講生数人に1週間ほど使ってもらい、意見を集める
- ☐ App Store Connect で「審査へ提出」（審査用メモは掲載情報のとおり）
- 審査は通常1〜3日。リジェクト（差し戻し）されたら、理由の画面をそのまま Claude に送ってください
