# 月額500円（プレミアム）の設定手順

アプリ側の仕組みは作成済みです。あとは **App Store Connect** と **RevenueCat** で、次の設定をしてください。
（所要時間の目安：初回 1〜2 時間。Apple の確認待ちで 1〜2 日かかることがあります）

## 無料と有料の範囲

| | 無料 | プレミアム（月額500円） |
| --- | --- | --- |
| 場面練習 | 各種類3本ずつ（36本） | すべて（120本） |
| 事実？解釈？クイズ | 16問（約25%） | 全60問 |
| 用語辞典 | 約800語（約25%） | 全3086語 |
| 自由記録・学ぶ・連続日数・目標・お知らせ | ○ | ○ |

無料の範囲は `src/lib/premium.ts` で決めています：場面は `id` が `-01`〜`-03` で終わるもの（`isFreeScenario`）、クイズは事実・解釈それぞれ4問に1問（`isFreeQuiz`）、用語は基本の161語＋用語ごとに決まった約2割（`isFreeTerm`）。

## 1. App Store Connect（Apple）

1. **契約・税金・口座**：App Store Connect →「ビジネス」→ **有料 App 契約** に同意し、銀行口座と税務情報を登録する（これがないと課金のテストもできません）。
2. **スモールビジネスプログラム**に申し込む：https://developer.apple.com/app-store/small-business-program/ （手数料が下がります）
3. アプリ →「サブスクリプション」→ **サブスクリプショングループ** を作る：名前「プレミアム」
4. グループの中に **サブスクリプション** を作る
   - 参照名：プレミアム月額
   - **製品ID：`kaigo_premium_monthly`**（あとから変えられません）
   - 期間：1か月
   - 価格：日本 **500円**（他の国は自動換算のままで可）
   - ローカリゼーション（日本語）：表示名「プレミアム」、説明「すべての場面で記録の練習ができます」
   - 審査用のスクリーンショット：アプリのプレミアム画面（設定 → プレミアム）
5. **お試し期間（おすすめ）**：「サブスクリプション価格」→「お試しオファー」→ 無料・**7日間**
6. **受講生向けオファーコード（受講生は無料にする場合）**：サブスクリプション →「オファーコード」→ 例「受講生 1か月無料」を作り、コードを発行して受講生に配る。受講生はアプリの「受講生コードを使う」から入力します。期間は1か月単位で、最長12か月まで選べます。
7. **App 内課金キー**：「ユーザとアクセス」→「統合」→「App 内課金」でキーを作り、.p8 ファイルをダウンロード（RevenueCat に登録します）。

## 2. RevenueCat

1. https://www.revenuecat.com でアカウントを作る（月の売上 2,500 ドルまでは無料）。
2. プロジェクトを作り、**App Store アプリ**を追加：Bundle ID `com.eikaysunflower.kaigokiroku`、上の .p8 キー（In-App Purchase Key）を登録。
3. **Products**：`kaigo_premium_monthly` を追加。
4. **Entitlements**：ID を **`premium`** にして作り、上の商品をひも付ける。
5. **Offerings**：`default` を作り（Current にする）、パッケージ **Monthly** に `kaigo_premium_monthly` を入れる。
6. 「API keys」の **Public app-specific API key**（`appl_` で始まる）をコピー。

## 3. アプリにキーを入れる（Mac で）

```bash
cd kaigo-kiroku-app
cp .env.example .env
# .env を開いて VITE_RC_IOS_KEY=appl_... に書き換える
npm run cap:ios
```

Xcode で「Signing & Capabilities」→「＋ Capability」→ **In-App Purchase** を追加します。

## 4. 購入のテスト（お金はかかりません）

1. App Store Connect →「ユーザとアクセス」→「Sandbox」で **テスト用 Apple ID** を作る。
2. iPhone の「設定」→「App Store」→ 一番下の「サンドボックスアカウント」にそのIDでサインイン。
3. Xcode から実機で起動 → 練習タブで 🔒 の場面をタップ → 「無料で試してみる」。
4. 確認すること：購入後に 🔒 が外れる／アプリを消して入れ直し →「購入を復元」で戻る／「受講生コードを使う」で入力画面が出る。

## 5. 審査に出す前のチェック

- [ ] プレミアム画面に「料金・期間・自動更新・解約方法・利用規約・プライバシーポリシー」が出ている（作成済み）
- [ ] 「購入を復元」ボタンがある（作成済み）
- [ ] App Store の説明文の最後に、利用規約（EULA）とプライバシーポリシーの URL を書く。アプリ内の文章（`src/data/info.ts`）と同じ内容を Web ページで公開して、その URL を使う
- [ ] App Store Connect の「App のプライバシー」：**購入 → 購入履歴**（用途：App の機能、ユーザに関連付けない、トラッキングなし）を申告。RevenueCat が購入状態の確認に使うため。学習データは端末内だけなので申告不要
- [ ] 審査メモに「プレミアムの場面は 練習タブの 🔒 から購入画面に進めます。Sandbox でテストできます」と書く
